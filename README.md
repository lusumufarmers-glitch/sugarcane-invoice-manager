# SugarCane Invoice Manager

First working Android prototype for authorized sugar-cane invoice management.

## Companies
- West Kenya
- Mumias/Butali

## Version 1 features
- Invoice search
- Farmer and invoice records
- Cancellation requests
- Admin approval/rejection
- Active/Pending/Cancelled status
- Basic dashboard
- GitHub Actions APK build

Invoices are not silently deleted. Cancellation requires an approval workflow and preserves the record status.
